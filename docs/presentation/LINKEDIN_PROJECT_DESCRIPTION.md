# LinkedIn Project Description

## **Option 1: Short & Professional (Recommended)**

**Sepsis Digital Twin: AI-Powered Early Detection System**

Developed an integrated machine learning system that predicts sepsis 4-6 hours before onset using ICU time-series data. Built an ensemble of 7 models (Logistic Regression, Random Forest, XGBoost, GRU-D, LSTM, CNN-LSTM, Transformer) trained on 546K+ real ICU records. Implemented a real-time Streamlit dashboard with 10 specialized tabs for patient monitoring, model explainability, and clinical workflow integration. The system combines clinical scoring systems (SIRS, qSOFA, SOFA) with advanced deep learning architectures to provide actionable risk assessments for healthcare professionals.

**Technologies:** Python, PyTorch, scikit-learn, Streamlit, Plotly, XGBoost, TensorFlow
